Green: 두 test가 통과하고, `node --test test/terminal.test.mjs`가 183개 중 183개 통과한다. `state` event는 재연결과 크기 변경 뒤에도 오므로 `inputHeld`를 지우지 않는다. `an exit event marks the session as ended and clears the held input without a warning`는 그 event가 지울 때 `a state event also follows a reconnect and a resize, and the session still holds the input`으로 실패했다(Red).
